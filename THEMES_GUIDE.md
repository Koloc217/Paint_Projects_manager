# Как создать тему оформления

**Русский** · [English](THEMES_GUIDE.en.md)

Мини-гайд для человека и для нейросети, которая делает тему. Тема меняет только вид (цвета, шрифты, рамки, фон,
графики); разметка, тексты и логика приложения не трогаются.

## 1. Как это устроено

- Тема = класс на `<body>` вида `theme-<имя>` (например `theme-neon`). Стандартный вид — без класса.
- Вся разметка собрана из классов Tailwind (`bg-slate-800`, `text-slate-400`, `bg-indigo-600`...), поэтому тема
  переопределяет **эти же классы** селекторами `body.theme-<имя> .bg-slate-800 { ... !important }`.
  `!important` обязателен: без него правила Tailwind с той же силой селектора могут перебить тему.
- Графики (Chart.js) рисуются на canvas и CSS не видят. Поэтому цвета и шрифт для них берутся из **CSS-переменных
  `--chart-*`**, которые тема задаёт в своём блоке (раздел 4). Приложение само перерисовывает графики при смене темы.
- Выбранная тема запоминается в браузере (`localStorage`, ключ `ph_skin`). Страница входа тоже применяет класс темы.

## 2. Что нужно сделать (3 шага)

1. **CSS-блок** в конец `static/themes.css`, обязательно между маркерами (по ним работает проверка):

   ```css
   /* === THEME: theme-neon === */
   body.theme-neon { ... }
   body.theme-neon nav { ... }
   /* === END THEME: theme-neon === */
   ```

2. **Регистрация** одной строкой в реестре `THEMES` в `static/app.js`:

   ```js
   { id: 'theme-neon', label: () => '🌈 Neon' },
   ```

3. **Шрифты** (если нужны не системные): шрифты лежат в приложении, без интернета. Добавить семейство с нужными
   начертаниями в `FONTS` в `tools/build_assets.py` (имя пакета [Fontsource](https://fontsource.org), например
   `"russo-one": (400,)`) и запустить `python tools/build_assets.py` (нужен Node.js), затем закоммитить
   `static/fonts/`. Шрифт **обязательно с кириллицей**: интерфейс русский.
   Картинки (фон, текстуры) кладутся в `static/backgrounds/` и подключаются относительным путём
   `url('backgrounds/имя.jpg')` (путь считается от `themes.css`). Внешние ссылки на картинки не используются.

Проверка: `python tools/check_theme.py theme-neon`, затем визуально (раздел 7).

## 3. Правила (контракт)

1. Каждый селектор в блоке начинается с `body.theme-<имя>`. Ничего «глобального» (`select {}`, `h1 {}`), иначе тема
   протечёт на остальные.
2. Менять **оформление**, а не вёрстку: цвета, фон, рамки, тени, скругления, шрифты, декор через `::before/::after`.
   Размеры, отступы, `display`, `position` самих элементов не менять (исключение: декор в псевдоэлементах).
   Нельзя прятать элементы (`display: none`), кроме иконки календаря `.dl-icon`.
3. Все свойства с `!important`, кроме `--переменных`, `transition`, `animation`, `content`.
4. Заданы **все** токены графиков (раздел 4) в правиле `body.theme-<имя> { ... }`.
5. У `body` заданы `background-color` (или `background`) и `color`. Контраст текста к фону не ниже 4.5:1
   (проверка `check_theme.py` умеет считать для `#hex`-цветов).
6. Имена анимаций начинаются с `<имя темы>-`: `@keyframes theme-neon-glow`. Свои `@font-face` и `@import` не
   использовать.
7. Декоративные псевдоэлементы: `pointer-events: none`, `z-index` не выше 40 (окна приложения от 60, подтверждение 95,
   уведомления 100).
8. Даты в карточках теперь с годом (`21.03.2027`, около 10 символов), плашки дедлайнов должны это переносить.
9. Не тяжёлые эффекты: без `filter: blur()` на больших блоках и бесконечных анимаций на десятках элементов.
10. Если шрифт даёт цифры «старого стиля» (в `05` ноль похож на `o`), добавить
    `font-variant-numeric: lining-nums` для `body`, `select`, `input`, `button`.
11. Телефон (экран уже 640 px, `static/mobile.css`): блок вкладок `#navTabs` становится нижней панелью, шапка
    перестраивается в две строки. Для этого у `nav` сбрасываются `transform`, `filter`, `backdrop-filter`,
    `clip-path`, `mask`, а `nav::before` / `nav::after` скрываются. Украшения шапки, рассчитанные на одну строку,
    на телефоне не видны. Цвета панели вкладок тема задаёт как обычно (`nav .bg-slate-900`, кнопки
    `nav button[id^="tab-btn"]`). Проверяйте тему и на ширине 375 px.

## 4. Токены графиков

Задаются в правиле `body.theme-<имя> { ... }`. Значения по умолчанию лежат в `:root` вверху `themes.css`.

| Токен | Что красит | Пример |
|---|---|---|
| `--chart-font` | шрифт подписей на графиках (должен быть доступен странице) | `'Alegreya', Georgia, serif` |
| `--chart-text` | подписи оси X и легенда | `#e6d5b8` |
| `--chart-muted` | подписи оси Y | `#b9a47a` |
| `--chart-grid` | линии сетки | `rgba(133, 103, 53, 0.35)` |
| `--chart-stage-1` … `--chart-stage-7` | столбцы «Воронка стадий»: без стадии, печать, шлифовка, сборка, грунт, покрас, доводка | `#5a4627` … |
| `--chart-series-1` | «Закрыто задач» | `#c9a227` |
| `--chart-series-2` | «Завершено проектов» | `#8b1a1a` |
| `--chart-border` | контур столбцов (`transparent` без контура) | `#f3e5ab` |
| `--chart-border-width` | толщина контура, число в px | `1` |
| `--chart-radius` | скругление столбцов, число в px | `0` |

Цвета для графиков задавать в `#hex`, `rgb()` или `rgba()`. Столбцы стадий должны различаться между собой, поэтому
шесть разных цветов, а не оттенки одного.

## 5. За что цепляться

Цвета Tailwind несут смысл. Страница: `slate-900`, карточки и окна: `slate-800`, поля и вложенные панели:
`slate-900`, вторичные кнопки и рамки: `slate-700`, обычный текст: `slate-300/400`.

| Что | Селектор |
|---|---|
| Страница | `body.theme-x` |
| Шапка | `body.theme-x nav`, вкладки `nav button[id^="tab-btn"]` (активная имеет класс `bg-slate-700`), счётчик `#tokenCounter` |
| Заголовки | `h1, h2, h3` |
| Карточки, окна, панели | `.bg-slate-800`, `.bg-slate-800\/90` |
| Поля и вложенные панели | `.bg-slate-900`, `input`, `select`, `textarea`, `select option` |
| Карточка проекта | `#projectsContainer > div` |
| Строка «Ближайшие задачи» | `#tasksContainer > div` |
| Другие списки | `#allTasksContainer`, `#hallOfFameContainer` |
| Кнопка «+ Проект» | `button.bg-emerald-600` |
| Кнопка «+ Задача», основное действие | `button.bg-indigo-600` |
| Кнопка «Сохранить» | `button.bg-blue-600` |
| Кнопка «Удалить» | `button.bg-red-600` |
| Вторичные кнопки (шестерёнка, «Отмена») | `button.bg-slate-700` |
| Дедлайны | `.text-xs > span` внутри карточек; состояния: `.text-red-500` просрочено, `.text-red-400` горит, `.text-slate-500` закрыто или без даты, `.text-slate-400` обычная; иконка календаря `.dl-icon` |
| Окна | `#settingsModal`, `#projectModal`, `#editProjectModal`, `#editTaskModal`, `#projectDetailsModal`, `#taskModal`, `#templateModal`, `#trashModal`, `#confirmModal`, `#lightbox`; уведомления `#toastContainer` |
| Вкладки настроек | `#settingsModal button[id^="cfgTabBtn"]` |
| Графики | только токены `--chart-*` |

Образцы лежат в самом `themes.css`: **Cyberpunk** (неон, угловые метки на кнопках), **Warhammer 40k** (бронза,
заклёпки, фон-картинка) и ещё шесть тем между маркерами `/* === THEME: ... === */` (SCP Dossier, Workbench,
Synthwave, JRPG, Model Manual, Hardware PCB). Новую тему удобно начинать с копии ближайшей по духу.

## 6. Минимальный каркас

```css
/* === THEME: theme-neon === */
body.theme-neon {
    /* графики */
    --chart-font: 'Orbitron', ui-monospace, monospace;
    --chart-text: #f5e9ff;
    --chart-muted: #b8a0d9;
    --chart-grid: rgba(255, 79, 216, 0.18);
    --chart-stage-1: #3a2f5a;
    --chart-stage-2: #4fd1ff;
    --chart-stage-3: #ffd84f;
    --chart-stage-4: #ff4fd8;
    --chart-stage-5: #9b6bff;
    --chart-stage-6: #4fffb0;
    --chart-stage-7: #ffb04f;
    --chart-series-1: #4fd1ff;
    --chart-series-2: #ff4fd8;
    --chart-border: transparent;
    --chart-border-width: 0;
    --chart-radius: 4;
    /* страница */
    background-color: #0d0a1a !important;
    color: #f5e9ff !important;
    font-family: 'Orbitron', ui-monospace, monospace !important;
}
body.theme-neon nav { background: #140f2a !important; border-bottom: 1px solid #ff4fd8 !important; }
body.theme-neon .bg-slate-800 { background: #1a1433 !important; border-color: #3a2f5a !important; }
body.theme-neon .bg-slate-900 { background: #120d26 !important; }
body.theme-neon select, body.theme-neon select option { background-color: #120d26 !important; color: #f5e9ff !important; }
body.theme-neon button.bg-indigo-600 { background: #7a2cff !important; }
/* ... кнопки, дедлайны, окна ... */
/* === END THEME: theme-neon === */
```

(В Orbitron нет кириллицы, он здесь только для краткости каркаса. Настоящей теме нужен шрифт с кириллицей.)

## 7. Проверка

1. `python tools/check_theme.py theme-neon`. Ошибки (✗) нужно исправить, предупреждения (!) просмотреть.
2. Открыть приложение, выбрать тему в выпадающем списке в шапке и пройти экраны:
   - дашборд: карточки проектов с дедлайнами всех видов (обычный, «горит», просрочено, закрыто);
   - колонка «Ближайшие задачи» и вкладка «Все задачи»;
   - вкладки «Календарь» и «Лента» (фото прогресса);
   - вкладка «Зал Славы & Аналитика»: оба графика и карточки завершённых проектов;
   - карточка проекта (окно): задачи, фото, референсы, рецепт красок, выбор шаблона пайплайна; окно корзины;
   - окна «Новый проект», «Новая задача», подтверждение удаления, уведомления;
   - настройки: все семь вкладок;
   - страница входа `/login`, если вход включён;
   - переключение на другую тему и обратно: графики должны перекраситься сразу, без перезагрузки.
3. Проверить на английском языке (Настройки → Основные → Язык интерфейса): подписи длиннее и не должны ломать рамки.

## 8. Типичные ошибки

- Забыли `!important`: часть элементов остаётся стандартной.
- Селектор без `body.theme-<имя>`: тема «протекает» на остальные.
- Шрифт без кириллицы: русский текст рисуется запасным шрифтом, вид «разваливается».
- Забыли какой-то токен `--chart-*`: график берёт стандартный цвет, `check_theme.py` это покажет.
- Светлый текст на светлом фоне в выпадающих списках: нужно задать и `select`, и `select option`.
- Фиксированная ширина или высота плашек: даты с годом и английские подписи длиннее.
- Тема не в реестре `THEMES`: в списке её не будет.
- Имя темы с заглавными буквами или подчёркиванием: допустимы строчные латиница, цифры и дефисы.

## 9. Готовый промт для нейросети

Скопируйте текст ниже, добавьте описание стиля и приложите скриншот интерфейса, `static/themes.css`
(как образец) и этот файл.

```
Ты делаешь тему оформления для веб-приложения (FastAPI + Tailwind, тёмный интерфейс, русский язык).
Стиль темы: <ОПИШИТЕ СТИЛЬ, ЦВЕТА, НАСТРОЕНИЕ, ШРИФТЫ>.
Имя темы: theme-<имя> (строчные латиница/цифры/дефисы).

Прочитай приложенный THEMES_GUIDE.md и соблюдай раздел 3 «Правила» буквально. Образцы — Cyberpunk и Warhammer
в приложенном themes.css.

Выдай ровно три блока кода и ничего больше, кроме одной строки пояснения к каждому:
1) CSS для конца static/themes.css между маркерами /* === THEME: theme-<имя> === */ и /* === END THEME: theme-<имя> === */.
   Каждый селектор начинается с body.theme-<имя>; все свойства с !important (кроме --переменных); заданы все
   15 токенов --chart-*; у body заданы background-color и color; шрифты только с кириллицей.
2) Одну строку для реестра THEMES в static/app.js: { id: 'theme-<имя>', label: () => '<эмодзи> <Название>' },
3) Список веб-шрифтов с начертаниями в виде имён пакетов Fontsource (например "russo-one": (400,)), либо слово «нет».

Нельзя: менять вёрстку и размеры, прятать элементы, подключать внешние картинки и @import, трогать селекторы без
префикса темы. Даты в плашках теперь вида 21.03.2027, не делай плашки фиксированной ширины.
Фоновые картинки не придумывай: используй градиенты и CSS-узоры, либо укажи имя файла, который я положу в static/.
```
