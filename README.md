# RPi5 Project Hub

Локальный трекер хобби-проектов (3D-печать и покраска миниатюр) для Raspberry Pi 5.
Веб-интерфейс, Telegram-бот, уведомления по расписанию и система «токенов»: новый проект стоит токены,
завершённый приносит награду. Идея в том, чтобы не бросать начатое и не копить нераскрашенные модели.

> Статус: личный проект «для себя». Работает на одном пользователе, данные хранятся локально.
> Подробное описание логики и API: [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md).

## Что умеет

**Проекты и задачи**
- Карточки проектов: статус, стадия (печать, шлифовка, сборка, грунт, покрас), приоритет, срок, фото.
- Поиск проектов в списке активных и в Зале славы: по названию, номеру, статусу, стадии, рецепту красок и названиям задач.
- Задачи с дедлайнами, статусами, переносом срока и редактированием.
- Референсы: изображения к проекту с просмотром на весь экран.
- Фото прогресса: снимки по ходу работы с датой и стадией, лента времени в карточке проекта и общая вкладка «Лента».
- Блокнот красок: рецепты и заметки по покраске прямо в карточке проекта.
- Шаблон пайплайна: выбор «3D-печать» (7 этапов) или «сборная модель» (6 этапов). Перед созданием открывается
  окно сроков: у каждого этапа своя дата, этап можно пропустить, а сроки можно распределить равномерно до даты проекта.

**Токены и мотивация**
- Баланс токенов: старт проекта стоит токены, завершение даёт награду.
- Зал славы: завершённые проекты, статистика и графики (воронка по стадиям, закрытые задачи и проекты за 6 месяцев).
- DEV MODE для тестов и правок баланса.

**Telegram-бот**
- Привязка к одному чату по коду, бот отвечает только привязанному чату.
- Команды и кнопки: список проектов, текущая задача, закрытие и перенос задач, смена статуса и стадии.
- Фото: пришли боту снимок (подпись станет заметкой), и он попадёт в ленту проекта. `/photo` показывает последние фото и листает их.
- Вечерняя сводка, пятничный дайджест, отчёт за месяц, предупреждение о застое проекта.
- Расписание по дням недели настраивается в интерфейсе.

**Оформление и язык**
- Восемь тем: стандартная, Cyberpunk, Warhammer 40k, SCP Dossier, Workbench, Synthwave, JRPG (FFVII), Model Manual, Hardware PCB.
  Графики подхватывают цвета темы. Как добавить свою: [THEMES_GUIDE.md](THEMES_GUIDE.md).
- Язык интерфейса, бота и уведомлений: русский и английский. Все тексты лежат в одном файле `locales.json`.
- Формат дат с годом на выбор: `21.03.2027` или `03/21/2027`.

**Безопасность**
- Необязательный вход по паролю, по умолчанию выключен. Включается в Настройки → Доступ.
  Первый вход под `admin` / `123456`, потом система требует сменить пароль.
- Пароль не передаётся открытым текстом (клиент отправляет хэш, сервер хранит scrypt).
- HTTPS в базовом варианте: строка `HTTPS=1` в `.env` включает шифрование, сертификат создаётся сам
  (см. раздел «HTTPS» ниже). Без HTTPS перехваченный хэш можно переслать повторно, поэтому в сеть интернета
  приложение без него выставлять нельзя.

**Резервные копии и надёжность**
- Автобэкап проектов и задач в Google Sheets через Apps Script. Фото в бэкап не входят.
- Если приложение было выключено во время пуша или бэкапа, после запуска пропущенный запуск выполняется сам.
- База SQLite в режиме WAL: веб, бот и скрипты пишут в неё одновременно без блокировок.

## Стек

Python 3.10+, FastAPI, SQLAlchemy + SQLite, Jinja2, httpx, Tailwind (CDN), Chart.js, Telegram Bot API.

## Запуск

```bash
git clone https://github.com/Koloc217/Paint_Projects_manager.git
cd Paint_Projects_manager
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env          # впишите TELEGRAM_BOT_TOKEN; PROXY_URL и APPS_SCRIPT_URL по необходимости
python app.py                 # веб, бот и планировщик одним процессом
```

Интерфейс откроется на `http://<адрес устройства>:8000`. Файлы `tracker.db`, `config.json`, `auth.json`
и папка `photos/` создаются при первом запуске и в git не попадают.

Привязка бота: Настройки → Telegram, получить код и отправить его боту в нужном чате.

## HTTPS

По умолчанию приложение работает по обычному HTTP. Чтобы включить шифрование, добавьте в `.env`:

```
HTTPS=1
```

и перезапустите приложение. При первом запуске само создаётся самоподписанный сертификат
(`certs/server.crt` и `certs/server.key`, срок 825 дней). В него входят `localhost`, имя и адрес устройства в сети
и всё, что перечислено в `TLS_NAMES` (например `TLS_NAMES=hub.local,192.168.1.50`). Порт остаётся прежним
(`PORT` в `.env`, по умолчанию 8000), только адрес теперь начинается с `https://`. Нужна утилита `openssl`
(на Raspberry Pi OS есть).

- **Предупреждение браузера.** Сертификат самоподписанный, поэтому на каждом устройстве один раз появится
  «соединение не защищено». Нажмите «Дополнительно → Перейти на сайт». Чтобы предупреждение исчезло, добавьте
  `certs/server.crt` в доверенные сертификаты устройства.
- **Если адрес устройства поменялся**, пересоздайте сертификат: `python tls.py cert --force`
  (или добавьте новый адрес в `TLS_NAMES`).
- **Свой сертификат** (например, от mkcert или Let's Encrypt): укажите оба пути, `SSL_CERTFILE` и `SSL_KEYFILE`.
- **Проверка:** `python tls.py status` показывает режим, порт и сколько дней осталось у сертификата.
  Во вкладке «Доступ» в настройках видно, по какому соединению открыта страница.
- Ключ `certs/server.key` никому не передавайте, папка `certs/` в git не попадает.

## Настройка

| Что | Где |
|---|---|
| Секреты (токен бота, прокси, адрес бэкапа), HTTPS и порт | `.env` (шаблон: `.env.example`) |
| Язык, формат даты, цена проекта, расписание, уведомления | Настройки в интерфейсе, хранится в `config.json` |
| Пароль | Настройки → Доступ; сброс из консоли: `python auth.py reset` |
| Фоновые картинки тем | `static/*_bg.jpg` (необязательно, без них тема рисует фон сама) |

## Известные ограничения

- Один пользователь, без ролей и прав.
- HTTPS по умолчанию выключен, а сертификат самоподписанный: шифрование есть, но каждое устройство один раз
  покажет предупреждение. Автоматического продления сертификата нет.
- Перенаправления с HTTP на HTTPS нет: порт один, и на нём работает либо HTTP, либо HTTPS.
- Бэкап не включает фото, референсы и фото прогресса.
- Догон пропущенных запусков ограничен: пуши в пределах 3 часов того же дня, бэкап в пределах суток, только последний запуск.
- База в режиме WAL: файл `tracker.db` на ходу копировать нельзя (остановите приложение или используйте `sqlite3 tracker.db ".backup копия.db"`).
- Названия задач из шаблона сохраняются на языке, который был активен при создании.
